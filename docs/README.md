## 🎯 设计原则

1. **业务优先**：先理清所有业务，再考虑技术实现
2. **端到端贯通**：从询价到结算形成完整业务闭环
3. **多角色协同**：货主、销售、操作、关务、客服、财务、海外代理在统一平台
4. **可扩展性**：支持多组织、多币种、多语言、多运输方式
5. **可配置化**：运价、附加费、费率、状态机均支持配置
6. **状态可追溯**：所有业务单据均有状态机和操作日志
7. **第二轮（v4.x）**：流程时序化、状态机转换表化、领域事件解耦、扩展点可插拔
