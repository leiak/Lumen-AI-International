# 国际物流系统设计方案 v1.0（设计稿）

> 全局设计总览，覆盖业务范围、用户角色、核心模块、流程、技术架构。

---

## 〇、设计原则

- **业务驱动**：覆盖国际物流全链路（询价→订舱→操作→运输→清关→仓储→派送→结算）
- **多角色协同**：货主、销售、操作、客服、财务、海外代理、承运人在同一平台协作
- **可扩展**：支持多组织、多币种、多语言、多时区
- **可集成**：通过 EDI / API 对接船公司、航司、海关、GPS 等
- **数据合规**：符合数据隐私、行业监管（AEO / IATA / IMO）要求

## 一、业务范围定位

### 1.1 主营业务

| 运输方式 | 子业务 |
| --- | --- |
| 海运（Ocean） | FCL 整柜、LCL 拼箱、特种柜（冷链/危险品/框架/开顶）、滚装 |
| 空运（Air） | 普货、危险品、温控、鲜活、急件、客带货 |
| 铁路（Rail） | 中欧班列、中亚班列、中老铁路 |
| 陆运（Land） | 跨境卡车、TIR 运输 |
| 多式联运 | 海铁联运、海陆联运、空铁联运 |
| 快递（Express） | DHL / FedEx / UPS / TNT 国际快递 |
| 仓储（WMS） | 国内仓、保税仓、海外仓、转运仓 |
| 报关清关 | 进出口报关、转关、AEO 认证 |
| 增值服务 | 拖车、装柜、贴标、打托、分拣、保险、换包装 |

### 1.2 服务对象

- **直接客户**：进出口贸易公司、跨境电商卖家、工厂、个人货主
- **同行客户**：货代同行、海外代理、跨境物流公司
- **内部团队**：销售、操作、客服、财务、关务、调度
- **外部协作方**：船公司、航司、铁路公司、拖车队、报关行、海外仓

## 二、用户角色与权限模型

### 2.1 系统角色

| 角色 | 主要职责 |
| --- | --- |
| 超级管理员（Super Admin） | 平台配置、租户管理 |
| 公司管理员（Tenant Admin） | 组织架构、权限、计费 |
| 销售（Sales） | 询价、报价、客户跟进 |
| 操作（Operations） | 订舱、拖车、报关、单证 |
| 关务（Customs Specialist） | 报关单证、HS 编码、查验跟进 |
| 客服（CS） | 异常处理、工单、客户回访 |
| 调度（Dispatcher） | 拖车、车队、运力资源调度 |
| 仓储（WMS Keeper） | 入库、出库、盘点 |
| 财务（Finance） | 应收应付、对账、开票、利润分析 |
| 客户（Customer） | 自助下单、查物流、对账 |
| 合作方（Partner） | 海外代理、承运人、仓库（受限门户） |

### 2.2 权限模型

- **RBAC + ABAC 混合**：基于角色的粗粒度 + 基于属性（部门、客户类型、业务线）的细粒度
- **数据隔离**：多租户隔离 + 同租户按部门/客户隔离
- **字段级权限**：报价、成本、客户价格等敏感字段脱敏

## 三、核心业务模块设计

### 3.1 报价与询价系统（Quotation）
- 运价库（按航线 / 承运人 / 柜型 / 有效期管理）
- 附加费库（动态加载：BAF、THC、ISPS、拥堵费、战争险）
- 报价模板（按客户等级、客户协议价）
- 在线询价（客户自助询价 → 自动 / 人工报价）
- 报价单 PDF / Excel 生成与邮件发送
- 报价历史与命中率分析

### 3.2 订单管理（Order / Booking）
- 委托单（Booking）：客户、起运港、目的港、货物信息、贸易条款
- 订单类型：FCL / LCL / 空运 / 铁路 / 陆运 / 多式联运
- 状态机：草稿 → 已确认 → 已订舱 → 已操作 → 已发运 → 已签收 → 已结算
- 改单 / 撤单流程与计费
- 多式联运段拆分（每段独立订舱 + 联运 ID串联）
- 客户自助下单 + 销售代客下单双通道

### 3.3 订舱与舱位（Booking & Space）
- 船期 /航班 / 班列时刻表
- 在线订舱（船公司 API / EDI / 人工）
- 舱位管理（截关 / 截港 / 开船 / 截重）
- 订舱确认与 SO（Shipping Order）下发
- 退舱与变更

### 3.4 操作管理（Operations）
- 拖车调度（自有车队 / 第三方车队）
- 装柜计划（装箱方案、拍照存档）
- 报关报检委托（与报关行协作）
- 提单（BL / AWB / RWB / SWB）制作与确认
- 补料（SI / VGM / AMS / ENS / AFR）
- 危险品 / 冷链特殊操作
- 单证归档（BL、发票、装箱单、合同、原产地证）

### 3.5 货物跟踪（Tracking）
- 节点事件采集（手工录入 / EDI / IoT / API）
- 跟踪时间线（Timeline）
- 异常预警（长时间无更新、偏离路线、延误）
- ETA预测（基于历史 + 实时数据）
- 客户可见跟踪页面（带 token验证的可分享链接）
- 自动通知（邮件 /短信 / 微信 / WhatsApp）

### 3.6 报关与清关（Customs）
- HS 编码库（带监管证件、税率、税率更新提醒）
- 进出口报关单据管理
- 一键生成报关草单
- 与单一窗口 / 各地海关系统对接（API / 客户端）
- 缴税通知与凭证
- 查验跟进
- AEO 认证企业资质管理
- 关务合规检查（禁限运、许可证）

### 3.7 仓储管理（WMS）
- 入库预约（ASN）
- 上架策略（按 SKU / 批次 / 库位）
- 库存管理（批次、SN、效期、保质期）
- 出库波次（按订单 / 承运人）
- 盘点（动态 / 静态 / 抽盘）
- 库内作业（拣货、打托、贴标、复核）
- 海外仓对接（Amazon FBA、第三方海外仓）
- 库存预警与调拨

### 3.8 财务结算（Finance）
- 应收（AR）：客户账单、对账单、收款核销
- 应付（AP）：供应商账单（船公司、车队、报关行、仓库）
- 自动计费引擎：按报价 + 实际作业生成账单
- 对账单生成与确认
- 开票/收票（发票管理）
- 多币种与汇率（CNY / USD / EUR / HKD，按日汇率 / 锁定汇率）
- 成本核算与利润分析（按订单、客户、业务线）
- 提成计算（销售提成规则引擎）

### 3.9 客户服务（CS）
- 客户档案（联系人、历史订单、偏好、特殊要求）
- 工单系统（异常、投诉、咨询）
- 知识库（FAQ / 流程文档）
- 自动回复机器人（FAQ）
- 客户回访与满意度

### 3.10 合作方管理（Partner）
- 船公司 / 航司 / 铁路公司档案
- 海外代理档案（含地址、联系人、付款方式）
- 拖车公司 / 报关行 / 仓库
- 协议价管理
- 合作方绩效（准点率、差错率、账期）
- 资质与证照管理（营业执照、运输许可、保险）

### 3.11 客户与销售管理（CRM）
- 客户线索 → 商机 → 报价 → 订单 → 复购
- 销售漏斗与预测
- 客户分级（VIP / A / B / C）
- 客户协议价 / 月结账期
- 客户访问记录

### 3.12 系统管理（Admin）
- 组织架构、用户、角色、权限
- 数据字典、业务编码
- 工作流配置（可视化流程引擎）
- 模板管理（报价单、提单、对账单）
- 操作日志与审计

## 四、关键业务流程

### 4.1 海运出口（FCL）主流程
```
询价 → 报价确认 → 委托单 → 订舱（船公司 SO） → 拖车 → 装柜 → 报关 → 放行 → 补料 → 提单确认 → 装船 → 在途跟踪 → 
卸港 → 换单 → 派送 → 签收 → 对账 → 结算 → 归档
```

### 4.2 海运进口主流程
```
国外发运 → 在途跟踪 → 换单（电放/正本） → 报关报检 → 缴税 → 
查验（可选）→ 放行 → 提柜 → 派送 → 签收 → 结算
```

### 4.3 空运出口主流程
```
询价 → 订舱 → 交货至机场货站 → 报关 → 安检 → 装机 → 
跟踪 → 提取 → 派送 → 签收
```

### 4.4 多式联运主流程
```
门点提货（陆运） → 集货仓 → 报关 → 铁路 / 海运 → 目的港 → 
清关 → 末端派送 → 签收
```

### 4.5 异常处理流程
```
事件触发（延误 / 改港 / 查验 / 货损） → 工单生成 → 责任判定 → 
方案制定 → 客户沟通 → 执行 → 关闭 → 复盘归档
```

### 4.6 财务结算流程
```
账单生成（应收） → 对账 → 客户确认 → 开票 → 收款核销 → 归档
账单生成（应付） → 供应商对账 → 付款 → 核销 → 归档
```

## 八、非功能设计

### 8.1 性能
- 订单查询 P95 < 300ms
- 跟踪事件写入 TPS > 5000
- 跟踪时间线 P95 < 500ms
- 报价计算 P95 < 200ms

### 8.2 可用性
- 核心服务 99.95% SLA
- 多可用区部署
- 数据库主从 + 读写分离 + 自动故障转移

### 8.3 安全
- TLS 1.2+ 全链路加密
- 敏感字段加密存储（AES-256）
- 接口签名 / 防重放
- RBAC + 数据权限 + 字段脱敏
- 防 SQL 注入 / XSS / CSRF
- 操作审计日志（保留 5 年）
- 数据脱敏（手机号、身份证、HS 编码等）
- WAF + 防爬虫

### 8.4 合规
- 《网络安全法》《数据安全法》《个人信息保护法》
- GDPR（涉及欧洲客户）
- AEO 认证（海关）
- IATA / IMO（空运 / 海运危险品）
- SOC2 / ISO 27001（可选）

### 8.5 国际化
- i18n：中文、英文、西班牙语、日语、韩语
- 多币种：CNY / USD / EUR / HKD / JPY / KRW
- 多时区：UTC + 本地时间
- 多税率：关税 / 增值税 / 消费税

## 十一、风险与挑战

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 海关接口不稳定 | 报关业务中断 | 重试 + 异步队列 + 异常工单 |

| 多客户数据隔离 | 客户隐私泄露 | 多租户 + 字段权限 + 审计 |
| 异常处理（SLA） | 客户流失 | SLA监控 + 自动预警 |
