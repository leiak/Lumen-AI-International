# 国际物流系统 - 业务表结构设计 v2.1

> 聚焦业务，不谈技术。所有表结构按业务实体设计，标注关键字段、枚举值与业务含义。
> v2.1：承接「第二轮 v4.0」深化，新增/扩展字段与状态口径依据 `15-表结构对账与待更新清单` 落位（状态机收敛→现有表补字段→新增表）。

---

## 一、业务全景图（实体关系总览）

```
【基础资料层】
客户档案 ─┐
联系人 ───┤
客户地址 ──┤
合作方档案 ┤── 报价 / 委托单 / 订单 ── 订舱 ── 运单 ── 跟踪事件
港口/航线 ┤                                    │
承运人 ────┤                                    ├── 报关单
HS编码 ───┤                                    ├── 提单/补料
仓库 ──────┤                                    ├── 仓储作业
包装/柜型 ──┘                                    │
财务（应收/应付/收款/付款）
                                              CRM（商机/跟进/工单）
```

## 十四、关键业务关系梳理

### 14.1 核心业务链

```
客户 ─委托→ 委托单 ─拆分→ 订舱 ─生成→ 提单 ─关联→ 报关单
                                 ↓
                       集装箱 ─产生→ 跟踪事件 ─触发→ 异常事件
                                 ↓
                       仓储入库/出库 ─产生→ 库存
                                 ↓
                  委托单 ─结算→ 应收账单 ←核销→ 收款
                  订舱 ─结算→ 应付账单 ←核销→ 付款
                  应收+收款 / 应付+付款 → 对账单
```

### 14.2 单据关联关系

| 主单 | 关联子单 / 单证 |
| --- | --- |
| 委托单 (t_order) | 报价、订舱、提单、报关单、应收账单、订单货物明细、服务项明细、跟踪事件、工单、文件 |
| 订舱 (t_booking) | 委托单、提单、补料、集装箱、订舱明细、跟踪事件 |
| 提单 (t_bl) | 订舱、委托单、补料、提单明细、跟踪事件、文件 |
| 报关单 (t_customs_declaration) | 委托单、订舱、提单、报关明细、关务单证 |
| 应收账单 (t_ar_invoice) | 委托单、应收明细、收款核销 |
| 应付账单 (t_ap_invoice) | 委托单、订舱、应付明细、付款核销 |
| 入库单 (t_wms_inbound) | 委托单、库存、入库明细 |
| 出库单 (t_wms_outbound) | 委托单、库存、出库明细 |
| 工单 (t_ticket) | 委托单、跟踪事件、异常事件、工单回复 |

### 14.3 状态机

| 业务单 | 状态机 |
| --- | --- |
| 委托单 | 草稿 → 待确认 → 已确认 → 已订舱 → 已操作 → 已发运 → 在途 → 已到港 → 清关中 → 已派送 → 已签收 → 已结算 → 已关账（含 已取消/已作废） |
| 订舱 | 待订 → 申请中 → 已订 → 已确认 → 已放舱 → 已截关 → 已装船（含 已退舱/已变更/已取消） |
| 提单 | 草稿 → 待客户确认 → 已确认 → 已签发 → 已修改 → 已放单 → 已电放（含 已作废） |
| 报关单 | 草稿 → 待申报 → 已申报 → 查验中/放行 → 已结关（含 已退单/已退关/已作废） |
| 应收账单 | 草稿 → 已生成 → 已对账 → 已确认 → 已开票 → 部分收款 → 已收款（含 已坏账/已红冲/已作废） |
| 应付账单 | 草稿 → 已对账 → 已确认 → 已收票 → 部分付款 → 已付款（含 已红冲/已退回/已作废） |
| 工单 | 待处理 → 处理中 → 已解决 → 已关闭（含 已转交/已升级/已重新打开） |
| 询价 | 待分配 → 已分配 → 报价中 → 已报价 → 已采纳/已拒绝/已过期/已关闭 |
