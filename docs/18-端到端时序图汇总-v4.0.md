# 端到端时序图汇总 v4.0

> 汇总第二轮各模块时序，供评审展示。以下时序为 Mermaid 源码，可直接渲染。
> 协作图统一缩写：客户/门户=C，销售=S，操作=O，关务=CS，仓储=W，财务=F，系统服务=SV，外部承运/海关/代理=EXT，跟踪=TRK。

---

## 一、海运出口 FCL 全链路

```mermaid
sequenceDiagram
  autonumber
  participant C as 客户
  participant S as 销售
  participant SV as 报价/订单服务
  participant O as 操作
  participant EXT as 承运人/海关
  participant TRK as 跟踪
  participant F as 财务
  C->>S: 委托需求/采纳报价
  S->>SV: 建委托单(引用报价)
  SV-->>SV: 校验信用/货量/危险品/HS(EP-2)
  S->>SV: 提交
  C->>SV: 确认(锁价锁汇率)
  SV->>EXT: 下订舱
  EXT-->>SV: SO/舱位确认
  SV->>SV: 委托单→已订舱
  O->>EXT: 拖车/装箱/补料/报关放行
  TRK->>SV: 装船事件
  SV->>SV: 已发运(里程碑M04)
  TRK->>SV: 在途→到港→放行→签收(M05..M09)
  F->>SV: 费用闭环/开票/回款
  SV->>SV: 已结算→已关账(M10..M12)
```

## 二、海运进口全链路

```mermaid
sequenceDiagram
  autonumber
  participant A as 海外代理
  participant TRK as 跟踪
  participant O as 操作
  participant CS as 关务
  participant EXT as 海关
  participant F as 财务
  A->>TRK: 到港预告/国外段跟踪
  TRK->>O: 到货通知/换单
  O->>CS: 进口清关申报
  CS->>EXT: 申报
  EXT-->>CS: 放行
  CS->>O: 提货/派送
  O->>F: 进口段费用结算/缴税
```

## 三、空运出口全链路

```mermaid
sequenceDiagram
  participant C as 客户
  participant SV as 订单/订舱
  participant EXT as 航司
  participant TRK as 跟踪
  C->>SV: 委托(货量/时效)
  SV->>EXT: 预定舱位(AWB)
  EXT-->>SV: 舱位确认
  O->>EXT: 建单/安检/收货/组板/交运
  EXT-->>TRK: 起飞(跟踪)
  TRK->>SV: 在途→中转→到达→清关→派送→签收
```

## 四、多式联运（段式）

```mermaid
sequenceDiagram
  participant SV as 委托单
  participant SEG as 段状态机
  participant TRK as 跟踪
  SV->>SEG: 主委托(多段: 陆运+海运+铁路)
  SEG-->>SEG: 各段独立状态机
  TRK->>SEG: 段间交接事件(换单/转运)
  SEG->>SV: 主状态=段合并结果
  Note over SEG,SV: 交接异常→跨段回溯责任
```

## 五、电商小包（仓+干线）

```mermaid
sequenceDiagram
  participant W as 海外仓/FBA
  participant O as 出库/装载
  participant SV as 干线订舱
  participant TRK as 跟踪
  participant C as 消费者
  W->>O: 出库单(打托/贴标/装箱)
  O->>SV: 干线订舱在途
  TRK->>SV: 全程跟踪
  SV->>C: 末端派送→签收/退货
```
