> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 商家 (B2B 客户) 通过独立 SPA `lumen-customer-web` (Vite 5174) 自助查货 (DO 列表 / 详情 / 轨迹 / POD) + 登录 / 选客户 / 我的资料. 4.5A 范围, 4.5B/4.5C/4.5D 各自 spec 接力. 累计 4.5A 末: 后端 +10 端点 / 12 单元 / 13 IT; 前端 +6 页 / 16 Vitest; V33 migration; 1 新模块 `lumen-customer`; 1 新前端工程 `lumen-customer-web`.

**Architecture:** V33 migration 加 `t_customer_user_link` (1 user ↔ N customer 多对多) + customer 角色 (id 14) + 7 RBAC 权限 (id 159..165) + 7 role-perm (id 321..327). `lumen-common/security/JwtUtil` 加 `aud` claim, `lumen-rbac/security/JwtAuthenticationFilter` 按 path 路由 `aud=admin` / `aud=portal`. 新模块 `lumen-customer` (薄门面): 3 controllers / 10 endpoints, 调既有 `DeliveryOrderService` / `PodService` 加的 customer 重载 (强制 `WHERE customer_id = ?`). 客户范围通过 `CustomerContext` (ThreadLocal) + 拦截器注入. 前端独立 Vite SPA `lumen-customer-web` (port 5174, VITE_AUDIENCE=portal, 独立 store, 独立 i18n).

**Tech Stack:** Spring Boot 3.2.5 + MyBatis-Plus 3.5.7 + Flyway 9.x + JJWT 0.11 + Lombok + JUnit 5 + Testcontainers. Vite 5 + React 18 + TS 5 + Antd 5 + ProComponents 2.7 + zustand 4 + Vitest 1 + RTL + MSW 2.

## 重要执行注意事项 (每次 PR 开头先读)

### 既有约定
1. **包命名**: `com.lumen.<module>.*` (lumen-customer 全部用 `com.lumen.customer.*`)
2. **MyBatis-Plus**: 实体 `@TableName("t_xxx")`, mapper 继承 `BaseMapper<T>`, 多租户用 `TenantContext.getTenantId()` (ThreadLocal)
3. **RBAC**: controller 上 `@PreAuthorize("hasAuthority('xxx:yyy:zzz')")`; 错误码用 `RbacException` / `<Module>Exception`
4. **DTO 校验**: jakarta.validation (`@NotBlank` / `@Size` / `@Email` 等)
5. **统一响应**: `R<T>` (lumen-common 既有) — 成功 `R.ok(data)`, 失败 `R.fail(code, msg)`
6. **测试**: JUnit 5 (`@Test` / `@BeforeEach` / Mockito `@Mock` / `@InjectMocks`), IT 用 `@SpringBootTest` + Testcontainers MySQL
7. **Flyway migration**: 编号连续 (V33), 必须 `ON DUPLICATE KEY UPDATE` 幂等
8. **commit message**: 沿用 4.4 约定 `feat(4.5A.x): ...` / `test(4.5A.x): ...` / `docs(4.5A.x): ...` / `fix(4.5A.x): ...`

### 客户范围执行铁律 (任何 PR 涉及 portal 端点必须遵循)
1. **任何 portal controller 方法** 第一行必须 `CustomerContext.requireCustomerId()` (拦截器已注入, 但显式断言防 NPE)
2. **任何 service 重载** 第一行必须用 `customerId` 做范围过滤, 不允许"先查后过滤"
3. **任何 customer 写操作** 必须 audit log, 带 `audience=portal` + `customer_id`
4. **任何 customer 查询结果** 必须 DTO 转换, 不返 `tenant_id` / `created_by` / `updated_by` 字段 (防止 staff 信息泄露)

### 每次 commit 前自检
- `mvn -pl <module> -am test` (本地模块单测)
- `mvn -pl <module> -am verify -DskipITs=false` (含 IT)
- 若改了 `lumen-common`: 跑 `mvn -pl lumen-common -am test` 后再跑 `mvn -pl lumen-customer -am test` (下游受影响)
- commit message 严格按 `<type>(<scope>): <subject>` 格式

```java
public String issueToken(Long userId, Long tenantId, List<String> roles, List<String> perms) {

public String issueToken(Long userId, Long tenantId, List<String> roles, List<String> perms,
                        Map<String, Object> extraClaims, String audience) {
    Map<String, Object> claims = new HashMap<>();
    claims.put("sub", userId);
    claims.put("tenant_id", tenantId);
    claims.put("roles", roles);
    claims.put("perms", perms);
    claims.put("aud", audience == null ? "admin" : audience);
    claims.putAll(extraClaims);
    return doIssue(claims);  // 沿用既有签发逻辑, 仅替换 claims map
}

// 新增 getAudience 方法:
public String getAudience(String token) {
    return parse(token).getAudience();

public Long getActiveCustomerId(String token) {
    Object v = parse(token).get("active_customer_id");
    return v == null ? null : Long.valueOf(v.toString());
```

```java
import com.lumen.customer.exception.CustomerException;

public final class CustomerContext {
    private static final ThreadLocal<Long> USER_ID = new ThreadLocal<>();
    private static final ThreadLocal<Long> CUSTOMER_ID = new ThreadLocal<>();

    private CustomerContext() {}

    public static void set(Long userId, Long customerId) {

        CUSTOMER_ID.set(customerId);

    public static Long getUserId() { return USER_ID.get(); }

    public static Long requireCustomerId() {
        Long id = CUSTOMER_ID.get();
        if (id == null) throw new CustomerException(401_002, "未激活客户身份");
        return id;
    }

    public static void clear() {
        USER_ID.remove();
        CUSTOMER_ID.remove();
    }
}
```

```java
package com.lumen.customer.security;

import com.lumen.common.security.JwtUtil;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;

@Component
@Order(Ordered.HIGHEST_PRECEDENCE + 100)
public class CustomerContextFilter extends OncePerRequestFilter {

    @Autowired
    private JwtUtil jwtUtil;

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        try {
            if (request.getRequestURI().startsWith("/api/customer/")) {
                // JWT 已由 JwtAuthenticationFilter 解析过, SecurityContext 有 userId
                Long userId = (Long) SecurityContextHolder.getContext().getAuthentication().getPrincipal();
                // 从 token 取 active_customer_id (重新解析, 因 SecurityContext 不存原始 claims)
                String authHeader = request.getHeader("Authorization");
                if (authHeader != null && authHeader.startsWith("Bearer ")) {
                    String token = authHeader.substring(7);
                    Long activeCustomerId = jwtUtil.getActiveCustomerId(token);
                    if (activeCustomerId == null) {
                        throw new com.lumen.customer.exception.CustomerException(401_002, "token 缺少 active_customer_id");
                    }
                    CustomerContext.set(userId, activeCustomerId);
                }
            }
            chain.doFilter(request, response);
        } finally {
            CustomerContext.clear();
        }
    }
}
```

注: 若既有 `getAuthentication().getPrincipal()` 不是 Long, 看既有 filter 怎么取 userId, 沿用同套路.

```java
package com.lumen.customer.security;

import com.lumen.common.exception.AuthException;
import com.lumen.common.security.JwtUtil;
import com.lumen.customer.dto.*;
import com.lumen.masterdata.entity.WmsCustomer;
import com.lumen.masterdata.mapper.WmsCustomerMapper;
import com.lumen.rbac.entity.SysUser;
import com.lumen.rbac.mapper.SysUserMapper;
import com.lumen.rbac.mapper.SysUserRoleMapper;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;

import java.util.*;

@Service
public class PortalAuthService {

    @Autowired private SysUserMapper userMapper;
    @Autowired private SysUserRoleMapper userRoleMapper;
    @Autowired private WmsCustomerMapper customerMapper;
    @Autowired private PasswordEncoder passwordEncoder;
    @Autowired private JwtUtil jwtUtil;

    public PortalLoginResponse login(PortalLoginRequest req) {
        SysUser user = userMapper.selectByUsernameAndTenant(1L, req.username());
        if (user == null || !passwordEncoder.matches(req.password(), user.getPasswordHash())) {
            throw new AuthException(401_003, "用户名或密码错误");
        }
        if (!userRoleMapper.hasCustomerRole(user.getId())) {
            throw new AuthException(403_002, "该账号未开通客户门户");
        }
        List<Long> customerIds = userRoleMapper.listCustomerIdsForUser(user.getId());
        if (customerIds.isEmpty()) {
            throw new AuthException(403_003, "账号未绑定任何客户");
        }
        if (customerIds.size() == 1) {
            return issueToken(user, customerIds.get(0));
        }
        // 多客户: 返 choices 不返 token
        List<WmsCustomer> customers = customerMapper.selectBatchIds(customerIds);
        List<PortalCustomerChoice> choices = customers.stream()
            .map(c -> new PortalCustomerChoice(c.getId(), c.getCode(), c.getName(), false))
            .toList();
        return new PortalLoginResponse(null, null, choices, user.getId(), user.getUsername(), user.getRealName());
    }

    public PortalLoginResponse selectCustomer(Long userId, Long customerId) {
        SysUser user = userMapper.selectById(userId);
        if (user == null) throw new AuthException(404_001, "用户不存在");
        if (!userRoleMapper.userLinkedToCustomer(userId, customerId)) {
            throw new AuthException(403_001, "无权访问该客户");
        }
        return issueToken(user, customerId);
    }

    public PortalMeResponse me(Long userId, Long activeCustomerId) {
        SysUser user = userMapper.selectById(userId);
        WmsCustomer c = customerMapper.selectById(activeCustomerId);
        List<Long> ids = userRoleMapper.listCustomerIdsForUser(userId);
        List<WmsCustomer> all = customerMapper.selectBatchIds(ids);
        List<PortalCustomerChoice> choices = all.stream()
            .map(x -> new PortalCustomerChoice(x.getId(), x.getCode(), x.getName(), x.getId().equals(activeCustomerId)))
            .toList();
        return new PortalMeResponse(user.getId(), user.getUsername(), user.getRealName(),
```

```typescript
  return cfg;

http.interceptors.response.use(
  r => r,
  async (err: AxiosError) => {
    if (err.response?.status === 401) {
      const refreshToken = useAuthStore.getState().refreshToken;
      if (refreshToken) {
        try {
          const r = await axios.post('/api/auth/portal/refresh', null,
            { headers: { 'X-Refresh-Token': refreshToken } });
          const { token, refreshToken: newRefresh } = r.data.data;
          useAuthStore.getState().setTokens(token, newRefresh);

          return http(err.config!);

          useAuthStore.getState().logout();
          window.location.href = '/login';
        }
      } else {
        useAuthStore.getState().logout();
        window.location.href = '/login';
      }
```

```typescript
interface AuthState {
  token: string | null;
  refreshToken: string | null;
  userId: number | null;
  username: string | null;
  realName: string | null;
  activeCustomerId: number | null;
  setLogin: (token: string, refresh: string, userId: number, username: string, realName: string, activeCustomerId: number) => void;
  setTokens: (token: string, refresh: string) => void;
  logout: () => void;
}

export const useAuthStore = create<AuthState>((set) => ({
  token: localStorage.getItem('access_token'),
  refreshToken: localStorage.getItem('refresh_token'),
  userId: null,
  username: null,
  realName: null,
  activeCustomerId: localStorage.getItem('active_customer_id') ? Number(localStorage.getItem('active_customer_id')) : null,
  setLogin: (token, refresh, userId, username, realName, activeCustomerId) => {
    localStorage.setItem('access_token', token);
    localStorage.setItem('refresh_token', refresh);
    localStorage.setItem('active_customer_id', String(activeCustomerId));
    set({ token, refreshToken: refresh, userId, username, realName, activeCustomerId });
  },
  setTokens: (token, refresh) => {
    localStorage.setItem('access_token', token);
    localStorage.setItem('refresh_token', refresh);
    set({ token, refreshToken: refresh });
  },
  logout: () => {
    localStorage.removeItem('access_token');
    localStorage.removeItem('refresh_token');
    localStorage.removeItem('active_customer_id');
    set({ token: null, refreshToken: null, userId: null, username: null, realName: null, activeCustomerId: null });

}));
```
