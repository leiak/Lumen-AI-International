# Iteration 4.3.2 — lumen-finance 多币种 + L2 终审 + 调账单

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this spec PR-by-PR. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal**: Extend `lumen-finance` with multi-currency (CNY + USD), L2 financial approval (separation of duties), and credit/debit note adjustments. Inherits 4.3.1 (V26/V27/V28, 6 entities, 16 endpoints, 67 unit + 16 IT + 138 Vitest).

**Architecture**:
- **No new Maven module** — extend `lumen-finance` (10th business submodule, established in 4.3.1)
- **Multi-currency via exchangerate.host** — daily @Scheduled sync, manual fallback on API failure
- **L2 approval as state machine extension** — `PENDING_L1 → PENDING_L2 → L2_APPROVED` (replaces 4.3.1's `L1_APPROVED` terminal)
- **Adjustments as first-class entity** — `t_billing_adjustment` with `source_invoice_id` FK, L1→L2 flow, CREDIT/DEBIT types
- **Tax-inclusive math (CNY style)** — `tax = amount * rate / (1 + rate)`, `net = amount - tax`

**Tech Stack** (unchanged from 4.3.1):
- Spring Boot 3.2.5 + MyBatis-Plus 3.5.7 + Flyway 9.x
- Aviator 5.4.1 (no new expression features; 4.3.1 sandbox carries forward)
- Vite 5 + React 18 + TS 5 + Antd 5 + ProComponents 2.7 + Vitest 1 + RTL + MSW 2
- Testcontainers MySQL 8.0 + Flyway for IT
- JUnit 5 (Jupiter), Mockito (no AssertJ)
- Awaitility for async IT assertions

## §3 数据模型 (3 新表 + 5 列扩展 + V29/V30 migrations)

### 3.1 `t_exchange_rate` (新表, V29)

```sql
CREATE TABLE t_exchange_rate (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  from_currency CHAR(3) NOT NULL,         -- 'USD' (本期唯一 from)
  to_currency CHAR(3) NOT NULL,           -- 'CNY' (本期唯一 to)
  rate DECIMAL(18,8) NOT NULL,            -- 7.12340000 (1 USD = 7.1234 CNY)
  rate_date DATE NOT NULL,                -- 2026-10-15
  source VARCHAR(32) NOT NULL,            -- 'EXCHANGERATE_HOST' / 'MANUAL'
  created_at DATETIME(3) NOT NULL,
  UNIQUE KEY uk_rate (from_currency, to_currency, rate_date, source)
);
```

- **数据特征**: append-only, 不修改历史
- **查询模式**: `SELECT * WHERE from='USD' AND to='CNY' AND rate_date <= today ORDER BY rate_date DESC LIMIT 1` (latest available)
- **多 source 优先级**: EXCHANGERATE_HOST > MANUAL (latest 优先, 但 MANUAL 可覆盖今天)

## §5 多币种 flow

### 5.1 汇率拉取 (后台)

```
@Scheduled(cron = "0 30 0 * * ?")   // 每日 00:30
  → RateSyncService.syncDaily()
    → ExchangeRateHostProvider.fetch("USD", "CNY", today)
       HTTP GET https://api.exchangerate.host/latest?base=USD&symbols=CNY
       返回 JSON: { "success": true, "rates": { "CNY": 7.1234 } }
    → RateSyncService 解析 → RateResponse { rate=7.1234, source=EXCHANGERATE_HOST, rateDate=today }
    → ExchangeRateService.saveRate(record)
    → INSERT t_exchange_rate (ON DUPLICATE KEY UPDATE rate=VALUES(rate))
    → log.info("Rate synced: 1 USD = {} CNY (date={})", rate, today)
    
失败处理:
  → log.error + 告警 (4.3.2 不做监控, 4.3.3 加)
  → 抛 RateSyncException (FinanceException RATE_SYNC_FAILED 400_008)
  → 不影响其他 cron / 业务
  → 后续 invoice 创建 fallback 到 t_exchange_rate 最近一条 (任意 source)
```

### 5.2 手动刷新 (admin / finance_manager)

```
POST /api/v1/finance/rates/refresh
  @PreAuthorize("hasAuthority('finance:rate:view')")
  → RateSyncService.syncDaily()  // 复用同一 service
  → 返回 R<Map> { today, rate, source, refreshedAt }
```

### 5.3 手动录入 (admin / finance_manager)

```
POST /api/v1/finance/rates/manual
```

## §6 L2 审批 flow

### 6.1 InvoiceService.l2Approve (新)

```java
@Transactional
public void l2Approve(Long tenantId, Long invoiceId, Long operatorId, String comment) {
    BillingInvoice inv = invoiceMapper.selectById(invoiceId);
    if (inv == null) throw new FinanceException(INVOICE_NOT_FOUND);
    TenantContext.assertTenant(inv.getTenantId(), tenantId);
    
    // 硬约束: L1 与 L2 不能同人 (separation of duties)
    if (inv.getL1ApproverId() != null && inv.getL1ApproverId().equals(operatorId)) {
        throw new FinanceException(L1_L2_SAME_OPERATOR, 
            "Same operator cannot L1 and L2 approve same invoice");
    }
    
    // 状态机
    StateMachineEngine.assertTransition("billing_invoice", "PENDING_L2", "L2_APPROVED");
    inv.setStatus(INV_STATUS_L2_APPROVED);
    inv.setL2ApproverId(operatorId);
    inv.setL2ApprovedAt(LocalDateTime.now());
    inv.setL2Comment(comment);
    invoiceMapper.updateById(inv);
    
    // 写 audit
    auditService.record(inv, "L2_APPROVE", null, INV_STATUS_L2_APPROVED, operatorId, comment);
    
    // 触发 finance 内部事件
    eventPublisher.publishEvent(new InvoiceL2ApprovedEvent(
        inv.getTenantId(), inv.getId(), inv.getInvoiceNo(), inv.getCurrency(), inv.getNetAmount()
    ));
}
```

### 6.2 InvoiceService.l2Reject (新)

```java
@Transactional
public void l2Reject(Long tenantId, Long invoiceId, Long operatorId, String comment) {
    if (comment == null || comment.isBlank()) {
        throw new FinanceException(INVOICE_REJECT_REASON_REQUIRED);
    }
    if (comment.length() > FinanceConstants.INVOICE_L2_COMMENT_MAX_LEN) {
        comment = comment.substring(0, 500);
    }
    BillingInvoice inv = invoiceMapper.selectById(invoiceId);
    if (inv == null) throw new FinanceException(INVOICE_NOT_FOUND);
    TenantContext.assertTenant(inv.getTenantId(), tenantId);
    
    // 职责分离
    if (inv.getL1ApproverId() != null && inv.getL1ApproverId().equals(operatorId)) {
        throw new FinanceException(L1_L2_SAME_OPERATOR);
    }
    
    StateMachineEngine.assertTransition("billing_invoice", "PENDING_L2", "REJECTED");
    inv.setStatus(INV_STATUS_REJECTED);
    inv.setL2ApproverId(operatorId);
    inv.setL2ApprovedAt(LocalDateTime.now());
    inv.setL2Comment(comment);
    invoiceMapper.updateById(inv);
    
    auditService.record(inv, "L2_REJECT", "PENDING_L2", INV_STATUS_REJECTED, operatorId, comment);
    
    eventPublisher.publishEvent(new InvoiceRejectedEvent(...));
}
```

## §7 调账单 flow

### 7.1 AdjustmentService.create (新)

```java
@Transactional
public BillingAdjustment create(Long tenantId, Long sourceInvoiceId, String type, 
                                BigDecimal amount, String reason, Long operatorId) {
    // 校验 source invoice
    BillingInvoice src = invoiceMapper.selectById(sourceInvoiceId);
    if (src == null) throw new FinanceException(INVOICE_NOT_FOUND);
    TenantContext.assertTenant(src.getTenantId(), tenantId);
    
    // 源 invoice 状态必须 ≥ L2_APPROVED (调账基于已批 invoice)
    if (!INV_STATUS_L2_APPROVED.equals(src.getStatus()) 
        && !INV_STATUS_PUSHED.equals(src.getStatus())) {
        throw new FinanceException(ADJUSTMENT_SOURCE_NOT_APPROVED,
            "Source invoice must be L2_APPROVED or PUSHED, current=" + src.getStatus());
    }
    
    // 校验 amount
    if (amount == null || amount.signum() <= 0) {
        throw new FinanceException(ADJUSTMENT_AMOUNT_INVALID);
    }
    if (reason == null || reason.length() < 10) {
        throw new FinanceException(ADJUSTMENT_REASON_REQUIRED);
    }
    
    // 跨币种调账禁止
    // (本期 adjustment.currency 必与 source.invoice.currency 一致; 暂不允许 user 改 currency)
    
    // 沿用源 invoice 汇率 + 税率
    BigDecimal fxRate = src.getFxRateAtCreation();  // 4.3.1 旧 invoice 为 null, fallback to 1.0
    BigDecimal taxRate = taxRateService.getActiveRate(src.getCurrency(), LocalDate.now());
    
    // tax-inclusive 计算
    BigDecimal taxAmount = amount.multiply(taxRate).divide(
        BigDecimal.ONE.add(taxRate), 4, RoundingMode.HALF_UP);
    BigDecimal netAmount = amount.subtract(taxAmount);
    
    // 编号 (内联, 4.3.1 模式)
    String adjustmentNo = "ADJ-" + tenantId + "-" + System.currentTimeMillis() + "-" + seq.getAndIncrement();
    
    BillingAdjustment adj = new BillingAdjustment();
    adj.setTenantId(tenantId);
    adj.setAdjustmentNo(adjustmentNo);
    adj.setSourceInvoiceId(sourceInvoiceId);
    adj.setAdjustmentType(type);  // CREDIT / DEBIT
    adj.setAmount(amount);
    adj.setCurrency(src.getCurrency());
    adj.setFxRateAtCreation(fxRate != null ? fxRate : BigDecimal.ONE);
    adj.setTaxRate(taxRate);
    adj.setGrossAmount(amount);
    adj.setTaxAmount(taxAmount);
    adj.setNetAmount(netAmount);
    adj.setReason(reason);
    adj.setStatus(ADJ_STATUS_DRAFT);
    adj.setCreatedAt(LocalDateTime.now());
    adj.setUpdatedAt(LocalDateTime.now());
    adjustmentMapper.insert(adj);
    
    auditService.record(adj, "CREATE", null, ADJ_STATUS_DRAFT, operatorId, reason);
    return adj;
}
```

### 7.2 AdjustmentService L1/L2 状态机 (复用)

调账单的 `submit` / `l1Approve` / `l1Reject` / `l2Approve` / `l2Reject` / `markPosted` 实现与 InvoiceService 同款, 但:
- 状态字符串: `ADJ_STATUS_DRAFT` / `ADJ_STATUS_PENDING_L1` / `ADJ_STATUS_PENDING_L2` / `ADJ_STATUS_L2_APPROVED` / `ADJ_STATUS_REJECTED` / `ADJ_STATUS_POSTED`
- audit table 共用 `t_billing_audit` (4.3.1 已建, 通用)
- L1 / L2 职责分离 assert 同 invoice

### 7.3 source_invoice_id 关联查询

`AdjustmentService.get(tenantId, id)` 返回 `View` 含 `sourceInvoiceNo` (join `t_billing_invoice.invoice_no`).

列表 query: `WHERE source_invoice_id = ?` filter; 报表 4.3.3 汇总.

## §14 风险

| 风险 | 缓解 |
