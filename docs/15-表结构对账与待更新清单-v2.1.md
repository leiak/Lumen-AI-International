## 〇、对账目的与方法

- **比对输入**：`02 表结构 v2.0`（27 张业务表 + 规则配置表） vs. 各 `-v4.0` 文档（状态转换表、字段联动、领域事件、EP 扩展点、里程碑）。

## 四、状态机口径收敛表（02 现状 → v4 目标）

| 业务单 | 02 现值 | v4 目标（需同步） |
| --- | --- | --- |
| 委托单 | 草稿→已确认→已订舱→已操作→已发运→已签收→已结算→已取消(8) | **15 态**：+待确认、清关中、已到港、已派送、已关账、已作废、已取消(完整) |
| 订舱 | 待订→已订→已确认→已放舱→已截关→已装船→取消(7) | **10 态**：+申请中、已退舱、已变更 |
| 提单 | 草稿→已确认→已签发→已放单→已电放→已作废 | 补「已修改」 |
| 报关单 | 草稿→已申报→查验中/放行→已结关→已退单 | 补「已作废、退关」 |
| 应收 | 草稿→…→部分收款→已收款 | 补「红冲、坏账、客户异议、撤回」 |
| 应付 | 草稿→…→部分付款→已付款 | 补「红冲、退回（差异协商）」 |
| 收款 | 待核→已核→已认领→已核销 | 补「异常、红冲」 |
| 工单 | 待处理→处理中→已解决→已关闭 | 补「已转交、升级、重开」 |

> 收敛原则：**02 与 v4 状态集合以各模块 `-v4.0` 文档为准**；落位 `02` 时统一同步状态枚举，避免双口径。

## 五、建议落位顺序（02 → v2.1）

1. 先落**状态机口径收敛**（第四节）——影响最大、收益最高。
2. 再落**现有表新增字段**（第二节）——按表逐张补齐、审计旧数据默认值。
3. 最后落**新增表**（第三节）——按依赖：事件出口→里程碑→段→利润快照→WMS→审批/规则/SLA。
