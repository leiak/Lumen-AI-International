# 订舱与操作业务细化 v3.0

> 订舱与操作是国际物流的执行核心——从舱位确认到提单签发，每一步都关系到货物能否按时、安全地送达。

---

## 〇、文档约定

每个业务模块按以下结构细化：
1. **业务边界** 2. **核心实体详解** 3. **业务规则** 4. **状态机**
5. **业务流程** 6. **与其他模块的交互** 7. **可配置项** 8. **异常与边界场景** 9. **报表与分析维度**

## 一、业务边界与范围

### 1.1 订舱操作的业务定位

```
委托单确认 ─→ 【订舱】 ─→ 【操作】 ─→ 提单/补料 ─→ 集装箱出运
                ↑            ↑
              舱位管理     拖车/装柜/报关
```

| 模块 | 业务范围 |
| --- | --- |
| 订舱 | 与承运人确认舱位（船公司/航司/铁路） |
| 操作 | 拖车调度、装柜、报关协调 |
| 提单 | 提单制作、确认、签发、放单 |
| 补料 | Shipping Instruction 补料管理 |
| 集装箱 | 集装箱动态跟踪 |

### 1.2 业务范围

**属于本模块：**
- 订舱单的全生命周期管理
- 截关/截港/VGM 截止时间管理
- 提单（BL/ AWB/ RWB/ SWB）的制作与放单
- 补料（SI）提交与跟踪
- 集装箱动态跟踪
- 拖车调度
- 装柜方案
- 危险品/冷链特殊操作

**不属于本模块：**
- 委托单本身（订单模块）
- 报关申报（关务模块）
- 应收应付（财务模块）
- 跟踪事件记录（跟踪模块）

### 1.3 与上下游模块的边界

### 2.3 订舱状态机

```
待订 ─→ 申请中 ─→ 已订 ─→ 已确认 ─→ 已放舱 ─→ 已截关 ─→ 已装船/起飞
  ↓       ↓        ↓        ↓         ↓         ↓
取消    拒绝     退舱      变更       取消      异常
```

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| 待订 | 委托单确认后待订舱 | 发起订舱 |
| 申请中 | 已提交承运人 | 等待确认 |
| 已订 | 承运人已接单 | 补充信息 |
| 已确认 | 承运人确认舱位 | 准备装柜 |
| 已放舱 | 承运人放舱位 | 准备装柜 |
| 已截关 | 已过截关时间 | 已完成 |
| 已装船/起飞 | 货物已装船/装机 | 在途 |
| 已退舱 | 舱位退回 | 重新订舱 |
| 已取消 | 订单取消 | 关闭 |
| 已变更 | 订舱变更 | 重新确认 |

### 2.4 订舱流程

#### 2.4.1 自动订舱流程

```
委托单确认 → 自动调用承运人 API/EDI → 等待确认 → 订舱成功 → 触发通知
```

#### 2.4.2 手工订舱流程

```
委托单确认 → 销售/操作通过邮件/电话订舱 → 收到承运人 SO → 录入系统 → 确认
```

#### 2.4.3 EDI 订舱流程

```
委托单确认 → 构造 EDI 报文（IFTMIN）→ 发送承运人 → 接收 IFTMIN 响应
                                                     ↓
                                              订舱确认（IFTSTA）
                                                     ↓
                                              自动更新订舱状态
```

### 2.5 截关/截港时间管理

| 截止类型 | 提前天数 | 业务影响 |
| --- | --- | --- |
| 截货时间 | ETD -1~3 天 | 货物进港截止 |
| 截关时间 | ETD -1~2 天 | 报关放行截止 |
| 截单时间 | ETD -1~2 天 | 单证提交截止 |
| VGM 截止 | ETD -1 天 | VGM 提交截止 |
| 危险品截止 | ETD -3~5 天 | 危险品单证截止（提前） |

> **业务规则**：截关前 4 小时开始预警；截关前 1 小时红色预警；超截关时间自动锁定订舱为"已截关"。

### 2.6 订舱渠道管理

| 渠道 | 适用承运人 | 优势 |
| --- | --- | --- |
| EDI（UN/EDIFACT） | 大型船公司（CMA、MSC、MSK） | 标准化、自动 |
| API | 数字化承运人 | 实时、自动 |
| 邮件订舱 | 中小承运人 | 灵活 |
| 在线订舱平台 | 部分承运人 | 可视化 |
| 微信/微信群 | 部分承运人 | 即时 |

```
草稿 ─→ 待客户确认 ─→ 已确认 ─→ 已签发 ─→ 已放单 ─→ 已电放
  ↓         ↓          ↓         ↓         ↓
作废    客户驳回     修改      补发       撤销
```

| 状态 | 含义 |
| --- | --- |
| 草稿 | 操作员编制中 |

### 5.4 提单确认流程

```

                                                  ↓
                                            操作员提交承运人

```

- 称重法 vs 计算法
- VGM 申报号用于海关放行

## 八、特殊货物操作

### 8.1 危险品操作

| 操作项 | 业务规则 |
| --- | --- |
| 客户资质 | 需危险品出口/进口资质 |

| 装柜 | 隔离要求（与普通货分开） |
| 标记 | 联合国编号、危险品标签 |
| 申报 | 危险品申报给承运人 |

## 十三、小结

订舱与操作是国际物流系统的**执行核心**，决定了客户货物的实际流转。本模块细化的关键：
1. **订舱是起点**：截关时间管理至关重要
2. **提单是核心单证**：关系到客户提货
3. **补料是合规要求**：AMS/ENS 等影响入关
4. **集装箱是物理基础**：状态机贯穿全程
5. **特殊货物（危险品/冷链/超大件）需特殊流程**
