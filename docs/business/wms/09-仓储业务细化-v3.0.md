# 仓储业务细化 v3.0（WMS）

> 仓储管理（WMS）是国际物流的"蓄水池"——集货、拆箱、分拨、打托、贴标，所有增值服务都在这里完成。

## 一、业务边界与范围

### 1.1 仓储的业务定位

```
出口集货 → 国内仓 → 拆箱/拼箱 → 报关 → 出运
进口分拨 → 海外仓 → 拆箱/分拣 → 派送 → 客户
跨境电商 → FBA 仓 → 上架 → 拣货 → 打包 → 出库
```

| 模块 | 业务范围 |
| --- | --- |
| 入库 | ASN 预约、收货、上架 |
| 出库 | 拣货、复核、打包、发运 |
| 库存 | 库存管理、库位分配 |
| 库内作业 | 打托、贴标、换包装 |
| 盘点 | 动态/静态/抽盘 |
| 海外仓 | FBA 头程、第三方海外仓 |
| 增值服务 | 打托、贴标、分拣 |

### 1.2 业务范围

**属于本模块：**
- 入库单（ASN）全流程
- 出库单全流程
- 库存管理（含库位、批次、效期）
- 库内作业（拣货、打托、贴标、复核）
- 盘点
- 调拨
- 海外仓对接
- 库位管理

**不属于本模块：**
- 运输（订舱模块）
- 报关（关务模块）
- 客户/合作方管理（基础资料）
- 应收应付（财务模块）

### 3.3 入库状态机

```
待到货 ─→ 部分到货 ─→ 已到货 ─→ 已上架 ─→ 已关闭
  ↓         ↓           ↓         ↓
取消    部分上架     异常      退货
                              ↓
                            残损处理
```

### 3.4 入库流程

```
ASN 预约 → 客户送货/我司提货 → 到货验收（核对单据）→ 卸货
                                                       ↓
                                            质检（可选）→ 上架（库位分配）
                                                       ↓
                                            系统入库 → 库存更新 → 单据归档
```

| 按温控 | 冷藏/冷冻 |

### 4.3 出库状态机

```
待拣货 ─→ 拣货中 ─→ 已复核 ─→ 已打包 ─→ 已发货 ─→ 已签收
  ↓         ↓         ↓         ↓         ↓
取消      缺货      异常      异常      退签
```

### 4.4 出库流程

```
出库指令（销售订单/调拨）→ 波次规划 → 拣货 → 复核 → 打包
                                                       ↓
                                            称重 → 贴标 → 出库 → 装车发运
                                                       ↓
                                            运单生成 → 跟踪 → 签收
```

### 4.5 拣货策略

| 策略 | 说明 |
| --- | --- |
| 按单拣货 | 一单一拣 |
| 按波次拣货 | 多单合并 |
| 按批次拣货 | 整批次出库 |
| 按 SKU 拣货 | 汇总拣货 |
| FIFO | 先进先出 |
| FEFO | 先到期先出 |

### 4.6 复核与打包

- 扫码复核（与出库单核对）
- 称重核对（重量异常预警）
- 拍照存档
- 打包（换箱、加固）
- 贴标（运单标签、产品标签）

## 十五、小结

仓储管理（WMS）是国际物流的"地面战场"。本模块细化的关键：
1. **入库是源头**：ASN 预约、上架策略
2. **出库是交付**：拣货策略、波次规划
3. **库存是核心**：数量准确性、效期管理
4. **库内作业是增值**：打托、贴标、分拣
5. **海外仓是新蓝海**：FBA、第三方海外仓对接
6. **盘点是质检**：确保账实相符
