## 一、业务边界与范围

### 1.1 通知与系统的业务定位

```
业务事件 ─→ 通知引擎 ─→ 模板渲染 ─→ 多渠道发送 ─→ 接收方
                                                          ↓
                                            回执反馈 → 系统日志
```

| 模块 | 业务范围 |
| --- | --- |
| 通知模板 | 模板管理与变量 |
| 通知发送 | 多渠道触达 |
| 消息中心 | 用户通知聚合 |
| 操作日志 | 审计与追溯 |
| 编码规则 | 业务单号生成 |
| 系统字典 | 数据字典管理 |

### 1.2 业务范围

**属于本模块：**
- 通知模板管理
- 通知触达（邮件/短信/IM/站内）
- 消息中心
- 操作审计日志
- 业务编码自动生成
- 系统字典管理
- 工作日与节假日配置
- 系统参数

**不属于本模块：**
- 业务模块本身
- 用户/权限（基础资料）

## 三、通知发送

### 3.1 通知触发

| 触发 | 类型 |
| --- | --- |
| 业务事件 | 订单确认/订舱/发运/到港/签收 |
| 异常事件 | 延误/改港/货损 |
| SLA 事件 | 超时预警 |
| 财务事件 | 账单生成/对账提醒 |
| 系统事件 | 登录提醒/密码重置 |

### 3.2 通知字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| notify_type | ✅ | 通知类型 |
| target_type | ✅ | 用户/客户/合作方 |
| target_id | ✅ | 接收方 |
| channel | ✅ | 渠道 |
| title | ✅ | 标题 |
| content | ✅ | 内容 |
| template_id | ✅ | 模板 ID |
| related_biz_type | ✅ | 关联业务类型 |
| related_biz_id | ✅ | 关联业务 ID |
| send_at | ✅ | 发送时间 |
| send_status | ✅ | 状态 |
| read_at | ⚪ | 阅读时间 |
| retry_count | ✅ | 重试次数 |

### 3.3 通知状态机

```
待发送 ─→ 发送中 ─→ 已发送 ─→ 已读
   ↓         ↓         ↓
发送失败   失败       退订
   ↓
 重试
```

### 3.4 发送策略

| 触发 | 渠道优先级 |
| --- | --- |
| 紧急（异常/SLA） | 短信 → 邮件 → 微信 |
| 普通（订单确认） | 邮件 → 站内 |
| 国际客户 | 邮件 → WhatsApp |
| 内部 | 钉钉/飞书 → 邮件 |

### 3.5 发送频率控制

- 同类型通知聚合（如多个跟踪事件）
- 防骚扰阈值（每日 ≤ N 条）
- 退订机制

### 3.6 通知失败重试

- 自动重试 3 次
- 间隔：1min / 5min / 30min
- 最终失败：人工处理
