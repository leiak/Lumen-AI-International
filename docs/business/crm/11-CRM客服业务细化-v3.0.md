## 一、业务边界与范围

### 1.1 CRM 与客服的业务定位

```
潜在客户 → 线索 → 商机 → 报价 → 订单 → 维护 → 复购 / 流失
                                              ↓
                                         工单支持
                                              ↓
                                       满意度反馈
```

| 模块 | 业务范围 |
| --- | --- |
| 客户档案 | 已与基础资料衔接 |
| 商机 | 销售线索 → 商机 → 签约 |
| 跟进 | 销售跟进记录 |
| 工单 | 客户工单与处理 |
| 知识库 | FAQ 与流程文档 |
| SLA | 客服响应时效 |

### 1.2 业务范围

**属于本模块：**
- 商机全生命周期管理
- 销售跟进记录
- 客户回访
- 工单系统
- 知识库管理
- SLA 管理
- 满意度评价
- 客户分级（与基础资料协同）

**不属于本模块：**
- 客户档案（基础资料）
- 订单/订舱（业务模块）

### 2.2 销售漏斗阶段

| 阶段 | 含义 | 概率 | 转化目标 |
| --- | --- | --- | --- |
| 线索 | 初步接触 | 10% | 初步接触 |
| 初步接触 | 客户回话 | 20% | 需求确认 |
| 需求确认 | 了解需求 | 40% | 方案报价 |
| 方案报价 | 已报价 | 60% | 谈判 |
| 谈判 | 价格/条款 | 80% | 签约 |
| 签约 | 已成单 | 100% | - |
| 丢单 | 流失 | 0% | - |

### 2.3 商机状态机

```
线索 ─→ 初步接触 ─→ 需求确认 ─→ 方案报价 ─→ 谈判 ─→ 签约
  ↓         ↓           ↓           ↓         ↓
丢单      停滞        暂停       搁置      丢单
                                                  ↓
                                                转订单
```

### 2.4 商机转化路径

```
商机签约 → 自动生成委托单 → 商机状态"已签约"
商机丢单 → 记录丢单原因 → 关闭
```

## 九、客户分级与流失预警

### 9.1 客户分级

详见基础资料。本模块补充业务规则：

| 等级 | 维护策略 |
| --- | --- |
| VIP | 专属客服 + 月度回访 + 优先响应 |
| A | 重点维护 + 月度回访 |
| B | 常规维护 + 季度回访 |
| C | 基础维护 |
| 潜在 | 转化跟进 |
| 流失 | 挽留/放弃 |

### 9.2 流失预警

| 指标 | 阈值 | 处理 |
| --- | --- | --- |
| 无下单天数 | >90 天 | 预警 |
| 投诉次数 | >3 次/季 | 预警 |
| 满意度下降 | 评分<3 星 | 预警 |
| 付款延期 | >3 次 | 预警 |

### 9.3 流失挽留

```
流失预警 → 销售主管介入 → 客户回访 → 流失挽留方案 → 升级处理
                                                          ↓
                                                挽回 / 确认流失
```

## 十五、小结

CRM 与客服是国际物流的"客户关系核心"。本模块细化的关键：
1. **商机是销售入口**：漏斗管理预测业绩
2. **跟进是销售过程**：频次与质量决定转化
3. **工单是服务窗口**：SLA 决定客户体验
4. **知识库是效率工具**：沉淀经验、降低培训成本
5. **满意度是改进依据**：持续提升服务质量
