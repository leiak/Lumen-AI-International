## 一、业务边界与范围

### 1.1 报关的业务定位

```
委托单 ─→ HS 编码 ─→ 报关草单 ─→ 申报 ─→ 查验/放行 ─→ 结关
                       ↓
                  关务合规检查（禁限运、税率、监管证件）
```

| 模块 | 业务范围 |
| --- | --- |
| 报关单 | 进出口报关单据管理 |
| HS 编码 | 商品预归类与税率管理 |
| 监管证件 | 许可证、商检证等管理 |
| 关务合规 | 禁限运、贸易管制检查 |
| AEO 认证 | 企业资质管理 |
| 查验 | 海关查验协调 |
| 缴税 | 关税与增值税缴纳 |

### 1.2 业务范围

**属于本模块：**
- 进出口报关单全流程
- HS 编码预归类服务
- 监管证件管理
- 关务合规检查
- 单一窗口对接
- 查验与放行跟踪
- 缴税与完税凭证
- AEO 认证管理

**不属于本模块：**
- 委托单本身（订单模块）
- 货物运输（订舱模块）
- 仓储作业（仓储模块）

### 2.3 报关单状态机

```
草稿 ─→ 待申报 ─→ 已申报 ─→ 查验中/直接放行 ─→ 已放行 ─→ 已结关
  ↓        ↓         ↓           ↓             ↓
作废    退回修改   退单      查验异常       退关
                                          ↓
                                        退运
```

| 状态 | 含义 |
| --- | --- |
| 草稿 | 关务编制中 |
| 待申报 | 准备提交海关 |
| 已申报 | 海关受理 |
| 查验中 | 海关查验 |
| 已放行 | 海关放行 |
| 已结关 | 货物实际离境或入境 |
| 退单 | 海关退回 |
| 查验异常 | 查验发现异常 |
| 退关 | 货物退运 |
| 已作废 | 流程作废 |

### 2.5 报关流程（出口）

```
委托单确认 → 关务员生成报关草单 → 单证收集 → HS 编码确认
                                                       ↓
                                            监管证件准备 → 客户/我司提供
                                                       ↓
                                            报关行审核 → 提交海关
                                                       ↓
                                            海关受理 → 申报成功
                                                       ↓
                                            查验（如有）/ 直接放行
                                                       ↓
                                            货物离境 → 结关
```

### 2.6 报关流程（进口）

```
货物到港 → 换单 → 进口报关申报 → 缴税 → 查验（如有）/ 放行
                                                       ↓
                                            提货 → 结关
```

                                                              ↓

#### 3.2.2 归类记录字段

#### 3.2.3 归类复用

- 客户再次委托时自动匹配
- 同类货品可复用
- 归类历史可查询

### 3.3 HS 编码校验规则

| 校验项 | 说明 |
| --- | --- |
| HS 编码有效性 | 必须存在于 HS 编码库 |
| 法定单位 | 必须匹配 HS 编码的法定单位 |
| 税率一致性 | 与基础资料税率一致 |
| 监管证件 | 自动判定所需证件 |
| 禁限运 | 自动判定是否禁限运 |
| 危险品 | 自动判定危险品 |

### 3.4 HS 编码与税率计算

```
应缴关税 = 申报价值 × 关税税率
应缴增值税 = (申报价值 + 关税) × 增值税率
应缴消费税 = (申报价值 + 关税) / (1 - 消费税率) × 消费税率
合计税额 = 关税 + 增值税 + 消费税
```

## 八、缴税管理

### 8.1 税种

| 税种 | 说明 |
| --- | --- |
| 关税 | 进口关税（出口一般免税） |
| 增值税 | 进口环节增值税 13%/9% |
| 消费税 | 特定商品 |
| 反倾销税 | 部分进口商品 |
| 特别关税 | 报复性关税 |

### 8.2 缴税流程

```
海关计税 → 生成税单 → 客户确认 → 缴税（银行/电子支付）→ 海关核注 → 凭证归档
```

### 8.3 缴税字段

| --- | --- | --- |
| declaration_id | ✅ | 报关单 |

### 8.4 缴税方式

- 客户自缴（默认）

### 8.5 缴税时效

- 超期产生滞纳金（每日 0.05%）

## 十五、小结

报关与关务是国际物流的"合规门槛"。本模块细化的关键：
1. **HS 编码是核心**：准确归类决定税率与监管
2. **监管证件是合规底线**：缺失即阻断
3. **单一窗口是趋势**：自动化对接提效
4. **查验协调是服务**：客户体验关键
5. **AEO 是加分项**：高级认证提升通关效率
